# 广东申论小题｜逐题作答与薄弱点总账

> 建立于2026-11-20。用于跨会话续教；按真实作答持续追加。不覆盖原答，不把非官方参考答案视为唯一标准，不依据少数正确题宣布知识点已掌握。
>
> 总纲：[申论小题通用逻辑与表达教学大纲](../../教学大纲/申论小题通用逻辑与表达教学大纲.md)。本档案记录已经发生的作答和反馈，不是一次性定性诊断。

## A. 教学与批改约定（2026-11-20已由学习者明确提出）

1. **大量真题贯穿整个教学。** 每一道题先独立作答，再看材料证据与批改；不因连续答对少量自拟题就跳过相应训练范围或宣布掌握。需要从未见过的真实卷检验独立迁移，记录题目是否熟悉。
2. **一题一停。** 每次收到答案，先完整批改并进行诊断、写入本总账，**停下来问“这题还有什么问题？”**；只有学习者说“没问题／继续”后才出下一题。不要在同一次批改末尾自动附下一道题。
3. **看整份答案的语义，不按机器式字面配对。** 问题部分已经交代主体和对象，措施部分可用省略、代称或共享主语；只要整个答案仍能明确措施的作用对象和所改变的障碍，就不能因为措施句少重复几个词而否定或扣分。不是所有问题必须机械一一对应，也不是老师提供的改写才算正确。
4. **反馈分层。** 区分①有证据的事实/关系错误，②重要信息遗漏，③表述成立但可选择优化，④仅为新词调用机会。对已成立的答案先予认可，不强迫换成更“高级”的术语。
5. **诊断不等于推断人格或固有弱点。** 学生自述的原因与可观测错误分别记录；单次作答写“待观察”，重复出现再提高优先级。记录可用的表达和纠正动作，不只记缺点。
6. **少让学习者管理AI。** 若使用Codex，优先做题目抽取、真题索引、原始出处定位和逐题题干/材料整理；教学顺序、挑题、批改和更新档案由主教老师负责。题目与解析应分离，避免提前泄题。仓库已有77份PDF并不等于都已逐题核验。

## C. 本轮自拟练习原始作答与逐题诊断

### E01｜卫生室坐诊时间（教学自拟）

- **材料要点：**基础诊疗设备已配齐、医务人员已安排；沿用旧坐诊时间，与农忙时村民有空就医的时间不合。
- **原答—问题：**“卫生室医务人员坐诊安排未落实，与村民看病时间错配，医疗设备短缺。”
- **原答—措施：**“根据村民看病时间，调整落实医务人员坐诊安排，购入医疗设备。”
- **有效内容：**“时间错配”准确、自然；“根据村民看病时间调整坐诊安排”准确回应障碍。
- **需要纠正：**材料未说人员没有按已有排班到岗，“坐诊安排未落实”失实；明说设备配齐，“设备短缺”和“购入设备”与事实相悖或无必要。
- **可能原因：**已找到正确问题后，追加了不由材料支持的常见问题及措施。无法单凭一次确定动机。
- **可执行动作：**将已具备条件和当前障碍分开；对拟新增措施逐项问“材料有没有已经有了？”。
- **合格低成本表达：**“坐诊时间与村民就医时间不匹配；根据农忙时就医需求调整时间。”

### E02｜服务队指导内容（教学自拟）

- **材料要点：**服务队按时指导，但只讲基础操作；企业升级后需要维护和工艺优化知识。
- **原答—问题：**“服务队指导无法真正解决企业问题。”
- **原答—措施：**“根据企业需求调整服务队的指导内容。”
- **有效内容：**两句都成立，措施准确；没有凭空要求新建队伍、加指导次数。
- **表达补充（可选）：**问题句概括的是效果，若需突出直接障碍，可写“指导内容与企业当前需求不符”。原答不是错误。
- **观察结论：**能独立找到不适配关系，但不据此宣布完全掌握。

### E03｜农产品检测中心（教学自拟）

- **材料要点：**检测设备正常；只有一名能操作仪器的人；缺冷藏设施，样品变质。
- **原答—问题：**“1. 检测中心技术人员不足 2. 部分样品对应的冷藏设施短缺”
- **原答—措施：**“1. 招聘，培训专业技术人员。2. 完善冷藏设施配置。”
- **有效内容：**两类条件缺口都保留，措施回应；没被“再购检测仪器”误导。
- **可选表达：**“检测仪器操作人员不足”比泛指技术人员范围更窄，但原答可用。
- **观察结论：**在这一道题中识别了条件缺口；不可从单次正例推出稳定掌握。

### E04｜社区养老试点申报（教学自拟）

- **材料要点：**甲社会组织有养老经验，想**牵头**申请，但规定只有街道所属事业单位可牵头；乙具备资格，却缺材料清单，窗口答复不一致。
- **原答—问题：**“甲：部分有经验单位申请资格受限。乙：申请提交材料和办理要求不明确。”
- **原答—措施：**“甲：调整申请规定，允许具备相关经验单位申请。乙：明确申请材料清单，明确办理要求。”
- **有效内容：**第一次在换场景时主动写出“申请资格受限”；乙的问题和措施准确，甲改变资格范围的方向正确。
- **需要补回：**“牵头”改变限制范围。省略后可能使人误解为甲完全无法作为任何身份参与申请；相应措施也要明确允许**牵头申请**。
- **可执行动作：**遇“只能、限于、必须”时，检查限制的具体动作、资格、角色；不是要求将材料逐字复述。
- **词义补充：**“牵头”是组织、协调、推进的主要负责角色；参与不等于牵头。

### E05｜农业技术服务平台未分派需求（教学自拟；当前最新）

- **材料要点：**农业技术信息平台、专家名单、联系电话、服务项目均已有；农户可提交需求，专家愿指导；**无人将待办需求分派给专家**，专家不知道服务对象，农户等不到回复。
- **原答—问题：**“平台没有有效对接农户需求和专家指导。”
- **原答—措施：**“安排平台工作人员，建设农业技术信息平台，对接专家和农户”
- **有效内容：**问题准确；“安排平台工作人员”并“对接专家和农户”可以结合前半句理解，方向正确，**不应因为措施中未重复“需求、指导、分派”字样就机械否定。**
- **需要纠正：**“建设农业技术信息平台”与材料已建的平台重复，不能改变眼前分派环节的障碍。
- **最小修改：**删除“建设农业技术信息平台”；可写“安排平台工作人员，及时对接专家和农户”，若需更明确可写“安排人员分派农户需求，联系专家”。
- **与E01和2025真题的联系：**已观察到“现成条件仍被再次建设”在不同情境出现，优先记录，但仍要用新题检验是否稳定。
- **本次停止点：**等待学习者对解释“牵头”、E05批改、今后练习安排提出疑问或表示“没问题／继续”；**不自动出E06。**

## D. 此前真题的已确认或待验证事项（从已有对话回收）

### 2024广东省考二卷第二题｜产业园与基层调研

- 学习者自述：曾把“龙头企业经营困难”当作后续“其他主体规模小、抗风险能力弱、带农能力有限”的原因，进而删掉前一独立信息。**确认的错误加工过程是自行建立因果后压缩事实**；不能因此推断其经常如此。
- 对策写“资金、制度保障”可为可讨论的政策工具，但原材料没有直接指明所有经营困难来自融资不足。应分析工具与障碍的作用关系，不应认为“帮扶经营困难企业”在操作层级上天然比资金支持更具体。
- 材料“平时没人管”可以写日常管理不到位；若又写“缺少管理人员”，需要材料提供人员短缺线索。
- 公共服务问题涉及教学质量和文化、医疗等配套，不能把所有障碍只写成一个设施问题。
- 已写对的要点不因老师能换一个“更高级”词就否定。

### 2025广东省考县镇卷第二题｜科技赋能农业

- 南药整块漏答的原因是学生明确表示**根本没读到**；属于阅读覆盖问题，不是南药专业词汇不会。
- 建议另建实验室，但材料明确已有实验室、缺关键前处理设备；与E05相似，属于对策增加既有条件。
- 企业科技项目部分：原文既写**牵头申报资格限制**，也写企业**不知道怎样参与或被排除在外**。原答“创新渠道不明确、部分企业排除在外”有证据，不应被判成纯粹误读；如篇幅允许补“牵头申报”更全面。
- 竹林上山道路不便影响机械使用；只写“机械化低”可能漏掉已给出的使用条件。后续看是否反复漏“工具使用的配套条件”。
- 智慧农业“加强宣传”有现实依据；示范效果、培训等是可选改善手段，不是唯一正确措辞。
- 学习者追加的南药答句抓住标准化、研究力量与研发/加工人才，不必为了新词重新大改。

### 2026广东省考省市卷第二题｜零碳园区

- 原答已区分运营人才与复合人才、运营与评价、区域绿能互济等方面。优化用语不能覆盖这些正确信息。
- 绿电交易、接入办法是材料中的具体障碍；原答区域协同有依据，补充办理办法是信息扩展，不应简单视为原有建议毫无价值。
- 曾自述见长句虽有现成术语，但难以在字数下提取“最小完整单位”；后续看能否同时保留对象、动作和限定。

## E. 接下来怎样组织大量真题

1. **先连续积累真题原始作答。** 至少包含广东不同年份、卷种、不同问法和国考对照；“材料熟悉度”单独记录，不把熟题复述当成独立迁移。
2. 每题记录：原题链接与材料范围、用户原句、主要得分信息、明确错误或遗漏、是否存在不必要的推断、表达调用、用时及字数（若未知就写未知）、一个或多个待验证观察，以及下一次复现方向。
3. **批改先完成整题检查，再挑当前最有价值的一处深入教。** 其他发现保留在总账中，不丢失；下次可轮换专项，避免复盘无限扩张。
4. 题目以真实原材料为主；可用短练练习一个转化动作，但不能长期只练单段“可预测”情境。安排不重复的真实题检验整题覆盖、字数和用时。
5. **每题最后停下确认。** 只有收到学习者的疑问或明确继续指令之后再展开下一题。跨会话先读本档案最新单元，避免重复询问已给信息。
6. 如果Codex辅助处理题库，只交付**忠实抽取的题干、材料、出处页码、题型、字数限制与可追溯索引**；官方/机构参考答案另存，不混到练习题前。教师负责教学与动态选题，不让学习者充当AI交接项目经理。
