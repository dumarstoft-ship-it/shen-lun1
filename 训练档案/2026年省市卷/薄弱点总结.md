# 2026年广东省考省市卷｜薄弱点总结（持续更新）

> 初次记录：2026-11-18。与[原始作答](./2026-11-18_原始作答.md)分开保存。以下是训练中确认的自述困难与待检验的诊断，不等同于官方评分结论。后续只根据真实答题再修订。

## 核心薄弱点：准确短语的提取与“最小完整表达”的组合

**考生自己的描述（2026-11-18）：**

> 材料中有现成的术语，但一般包在很长的话里。只抄其中的术语，觉得这件事没说明完整；整句话搬过来，又太啰嗦、容易超字数。于是只能临场用自己的话重写。另一方面，熟悉上位概括，具体层级的术语与句式调用不够熟；以前还有过写超字数、导致后面要点写不下的经历。

**需要与其他问题分开辨认：**

1. **术语提取障碍：**能看懂长句，也能识别其中某个规范短语，但不容易分辨哪些限定信息必须一起保留，形成能够独立作答的短句。
2. **概括层级过高：**只摘上位词（如“完善考核机制”“加强服务”）显得不完整，漏掉对象、动作、环节或问题性质。
3. **字数风险控制：**担心展开一个点占用过多格子、挤掉后面的点，因此倾向“一刀切”高度概括。
4. **被迫重新措辞：**介于“只抄术语不完整”和“照抄原句太长”之间，转而临场用自己的话压缩；这本身不是错误，但增加措辞成本，也可能损失原文的精确度。

**目前更准确的诊断：**不是简单的“不会概括”或“缺少术语”，而是**从较长材料中抽取必要的术语＋限定信息，再合成低字数、意思完整的作答单位**这一环节不稳定。上述原因来自自我报告与本卷表现，仍需后续实战验证。

## 本卷具体例子（小题二）

| 原始答案表达 | 潜在信息损失 | 一种低字数保留方式（教学示例） |
|---|---|---|
| “部分园区没有长期运营，评价考核机制没跟上。” | “长期”容易被误读为运行时间不足；材料涉及建成后缺少实质运营，以及企业变化后的持续评价 | “建成后缺实质运营，动态评价滞后。” |
| “完善评价考核标准，加强对园区运营的监督。” | 没有点明跟踪什么变化、评价什么结果 | “跟踪企业变化，动态评价零碳成效。” |
| “协同周边区域互济绿色能源，共享配套设施。” | 区域协作方向正确，但没直接回应怎么买绿电、怎么接入的困难 | “明确绿电直连交易和接入办法，完善配套。” |
| “引进、培育高素质人才。” | “高素质”不能交代实际紧缺的人才类型 | “引育运营管理与复合技术人才。” |
| “为园区建设提供专家指导。” | 没体现方案设计论证、建设、运营等前后环节的服务需求 | “提供方案设计论证及全流程服务。” |

注意：上表是训练中的压缩示例，必须和原题材料再次核对；不能把“设计论证困难”改成“没有方案”，也不能把“动态评价”替代“实际运营”。

## 拟验证的微方法（不另外发明完整模板）

**材料长句 → 找可用术语 → 补足这个术语独立作答所必需的对象、动作或限定 → 删除无信息增量的修饰 → 检查是否仍回答设问。**

记忆单位不只是单词，而是**“术语＋必要搭配/限定”**：

- “动态考评” → “跟踪企业变化，动态评价零碳成效”。
- “重建设轻运营” → 用于“建设积极、建成后缺实质运行”的证据；不可仅凭暂未开门就作此判断。
- “全流程服务” → 说明具体覆盖哪些环节；不要误换成“全产业链”。
- “分类施策” → 须说明根据什么差异分类；不能与“分步实施”混用。

**字数处理：**先给所有要点留位置，再对每个点保留一个最能区别于其他点的对象/动作，不追求逐点等长；避免为了追求漂亮句式重新写长句。

## 后续如何判断有无改善

- 材料出现长句术语时，能否在较短时间内提炼出**短而完整**的句子，而不是只有孤立的词。
- 是否保留关键对象、动作及问题性质，不把“不会做”改成“不想做”、把“设计困难”改成“缺乏方案”。
- 在字数限制内，是否避免前半段展开过多、后半段不得不删去要点。
- 对策是否精准对应材料中的实际障碍，而不是停留在普遍正确的政策口号。

## 已确认的正面能力

- 能迅速找到较高层的归纳类别，覆盖面意识较强。
- 第一组术语辨析练习中，两题均选对：**B（重建设轻运营）、C（管护不到位）**，表明对两个概念的理解已初步明确。下一步重点验证能否在**没有选项、限字写作**时主动调用。

## 训练边界

**先验证当前方法，不因新想法立即推翻训练路线。** 只要原答案已经准确、完整且符合字数，就不为换成更高级术语而修改。原始答卷永不覆盖。
